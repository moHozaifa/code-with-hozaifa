## 📚 What I Am Learning

Through this project, I am starting my journey into **Git and GitHub**.

Some of the important concepts I am currently learning include:

### Git

Git is a version control system that helps developers track changes in their projects. It allows us to save different versions of our work and return to previous versions when needed.

### GitHub

GitHub is a platform where developers can store, manage, and share their Git repositories. It also makes collaboration with other developers easier.

### Repository

A repository, or **repo**, is a place where a project and its files are stored. This repository is my first step toward organizing and sharing my learning projects.

### Commit

A commit is like a saved version of the changes made to a project. Each commit can have a message explaining what was changed.
